# 0012 — Causal modeling (do-calculus/SCM) is deferred, not rejected

## Status
Accepted as a deferred capability. Activation condition not yet met.

## Context

A formal causal model requires dozens of real observations, which do
not yet exist. There is an architecturally meaningful difference between
"postponed until data exists" and "discarded as a bad idea," and that
distinction needed to be preserved explicitly.

## Decision

Deferred capability with an explicit activation condition: 20-30+
publications and a recurring pattern not explainable by simply reading
the log.

## Consequences

Not implemented. The activation condition has clearly not been met —
Experiment Log itself does not exist yet, so there are zero logged
observations to draw a pattern from.

## Validation
Not applicable.

## Reversal condition
Activation condition as stated above: 20-30+ publications plus a
recurring, log-unexplainable pattern.

## Source
Unanimous agreement across three independent architectural reviews.
